你需要两样东西：它叫什么，以及它在哪。凑齐这两样，通常要来回两趟，还得手动整理一下。

两种方式

复制整页，或者只复制你选中的那段

一个快捷键取标题和链接；另一个把你选中的内容一并带上，引用和出处一次到位。

粘进你的笔记里

Notion、Obsidian、文档、工单、聊天窗口。粘过去就是一条真正的链接，不是两行待整理的文本。

你的格式

标题、URL、URL 的各个部分、选中的文字，都有占位符；随意组合，绑到你顺手的快捷键上。

无需账号，不同步，不做统计。你的模板和复制过的页面只留在本机，而且源码公开，可以自己查。

常见问题

完全免费吗？

是的，Link & Title Copy Pro 是开源的，并且永久免费。没有任何隐藏收费。

它会收集我的数据吗？

绝对不会。我们不收集、存储或传输任何用户数据。所有操作都在你的浏览器本地完成。请查看我们的隐私政策。

我可以创建自定义格式吗？

可以！你可以使用 {title} 和 {url} 等变量创建无限数量的自定义模板。

默认使用哪些快捷键？

安装后自带三个：Ctrl+Shift+P 复制标题和网址，Ctrl+Shift+L 复制成 Markdown 链接，Ctrl+Shift+U 把选中的文字连同出处一起带上。macOS 上对应 Command 键。这些都可以改，也可以自己新增。

可以一次复制多个标签页吗？

可以。打开弹窗切到「全部标签页」，勾选需要的，用你选的模板一起复制。免费版一次最多 5 条。
